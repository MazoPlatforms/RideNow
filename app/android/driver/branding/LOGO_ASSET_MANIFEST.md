# RideNow Driver Logo Asset Manifest

Same resource layout and file names as the Rider app. Artwork comes from the supplied `RideNow-Driver-logos.zip`; the source originals are not bundled.

| Resource (`app/src/main/res/`) | Use |
|---|---|
| `drawable-nodpi/ridenow_mark_dark.png`, `ridenow_mark_light.png` | Symbol (R, pin and driver) for dark and light screens (`LogoMark`). |
| `drawable-nodpi/ridenow_wordmark_dark.png`, `ridenow_wordmark_light.png` | "RideNow" with the DRIVER label, text only (`Wordmark`). Cropped from the supplied stacked lockup. |
| `drawable-nodpi/ridenow_logo_dark.png`, `ridenow_logo_light.png` | Stacked symbol and wordmark lockup (RideNow_Driver_Brand_Assets.zip). |
| `drawable-nodpi/ridenow_launcher_foreground.png`, `ic_ridenow_monochrome.png` | Adaptive and themed launcher icon artwork. |
| `drawable-nodpi/ridenow_system_splash_dark.png`, `ridenow_system_splash_light.png` | Android 12+ system splash icon. |
| `drawable-nodpi/ridenow_from_sifric_dark.png`, `ridenow_from_sifric_light.png` | "from Sifric" credit on the splash (shared with the Rider app). |
| `drawable-*dpi/ic_stat_ridenow.png` | Notification small icon (white symbol silhouette). |
| `drawable/*_inset.xml`, `mipmap-anydpi*/ic_launcher*.xml` | Insets and launcher definitions, identical to the Rider app. |
