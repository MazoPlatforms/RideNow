# Driver app branding and artwork manifest

## Supplied Driver marks

The two source files are 1254 × 1254 RGB PNG marks with solid backgrounds; they are icon-only RideNow Driver artwork, not separate wordmarks. The white-background original contains the dark/yellow mark and the black-background original contains the white/yellow mark. The build script derives transparency from each matte and preserves the source files unchanged.

| Source | Derived use |
| --- | --- |
| `source/driver_icon_light_background_original.png` (copied from `file_00000000953c8208b46cf9d48a6ce1ca.png`) | `driver_mark_light.png`, light/dark horizontal and stacked wordmarks |
| `source/driver_icon_dark_background_original.png` (copied from `file_00000000fb808208849a30e62e0a382c.png`) | Adaptive/legacy launcher foreground, Android splash mark, monochrome mark, notification icon |

Generated raster marks are transparent PNGs. Wordmarks are intentionally separate from icon-only assets so they are not placed into launcher or notification slots. Adaptive foreground artwork is centered within a transparent canvas with a conservative safe-zone scale; legacy and round launchers use a dark square field and the same optically centered mark. Android 13+ themed icon and notification resources contain only a white alpha silhouette.

## 2026-10-20 scene and screen-branding correction

The seven current screens now use the original native `DriverCityArtwork.kt` composition (sun, skyline, Lotus Tower, water, foliage and curved road), with theme palettes and screen-specific depths. See `fidelity-20261020/AUDIT.md` and `reference-inventory.json` for all 26 reference pairs and the 19 unimplemented references.
