The unchanged contents of the supplied `RideNow-Android.zip` live in `app/android/`. The original archive is also retained at `app/android/RideNow-Android.zip`.

The Android project contains the provided splash screen and placeholder only. This workflow does not add backend integration or application features.

## Build and release

In GitHub Actions, select **Android APK preview → Run workflow → main**. Publishing is manually triggered so ordinary source edits do not automatically create public releases.

The workflow uses Java 17, Gradle 8.9, and Android SDK 35. It creates a wrapper in a separate temporary Gradle project, then copies only `gradlew`, `gradlew.bat`, and the wrapper JAR into the build workspace. The provided `gradle-wrapper.properties` is preserved. Generated wrapper files are not committed back to the repository.

After `:app:assembleDebug`, the workflow verifies the APK signature, checks every tracked Android source file against its pre-build SHA-256, and checks that Git sees no source modifications. A separate job with release-write permission publishes a prerelease containing:

- `RideNow-Android-splash-debug.apk`: installable debug APK.
- `RideNow-Android.zip`: the original uploaded archive, unchanged.
- `SHA256SUMS.txt`: release-asset checksums.
- `ANDROID_SOURCE_SHA256SUMS.txt`: source snapshot checksums.

The build job has read-only repository permission and does not receive production environment secrets. No signing secret is needed for this debug preview. Debug signing keys are generated by the Android tooling and can differ between runs, so an older preview may need to be uninstalled before a new preview can be installed. Production signing is a separate future setup.

Download the APK from the repository's **Releases** page. On Android 8.0 or newer, allow installation from the browser/file-manager when prompted. The release is explicitly marked as a splash preview.
