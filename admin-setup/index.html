முதல் Admin அமைப்பு

இந்தத் தற்காலிக அமைப்பை முடிக்க தனிப்பட்ட setup key தேவை. முதல் admin உருவானதும் setup மூடப்படும்.

தனி admin எண்ணைப் பயன்படுத்துவது சிறந்தது. ஏற்கெனவே rider ஆக உள்ள எண்ணைப் பயன்படுத்தினால் அதன் account admin ஆக மாறும்.

முதல் setup-ல் உங்கள் தனிப்பட்ட setup key உரிமையாளர் அனுமதியாகப் பயன்படுத்தப்படும். தொலைபேசி எண் WhatsApp மூலம் உறுதிப்படுத்தப்படாது.

RideNow, 6 digits, 30 seconds என்ற அமைப்புடன் secret-ஐ உங்கள் authenticator செயலியில் உள்ளிடுக.

Recovery password-ஐப் பாதுகாப்பாகச் சேமிக்கவும்

இது ஒருமுறை மட்டுமே காட்டப்படும். OTP அல்லது TOTP கிடைக்காதபோது login password-உடன் இதையும் பயன்படுத்தலாம். Recovery login செய்தால் இது மாற்றப்பட்டு புதிய recovery password வழங்கப்படும்.
